## Candidatas e possíveis traduções

Quando não houver: **nenhuma candidata nova; tradução potencial não identificada**.
Não inventar uma resposta inglesa para ocupar esta seção.

Para cada candidata compartilhada:

| Campo | Conteúdo obrigatório |
| --- | --- |
| Estado | Alegação externa não reproduzida / saída mecânica / candidata contextual não validada / tradução validada |
| Entrada | Dígitos, espaços, pontuação, ID da amostra e fonte exatos |
| Algoritmo | Versão congelada, chave, parâmetros e comando que produz a saída |
| Saída literal | Texto inglês/outra língua exatamente emitido; lacunas explícitas; referência ao conjunto de alternativas se houver |
| Seleção | Por que esta candidata foi mostrada, quantas alternativas/modelos foram examinados e qual critério a escolheu |
| Lore | Qual contexto independente a apoiaria ou contradiz; separar inferência da transcrição |
| Transferência | Previsões fixadas antes de ver a resposta; fontes não usadas no ajuste e dependências auditadas |
| Controles | Recuperação em positivos, desempenho nos nulos, limites e casos de falha |
| Confirmação pendente | Observação que permitiria confirmar ou descartar; não usar opinião de que “soa tibiano” como validação |

Uma palavra curta isolada pode constar como diagnóstico, sem ser chamada de
tradução promissora. Traduções alegadas por terceiros permanecem atribuídas ao
autor até reprodução e validação próprias. Nunca corrigir a saída silenciosamente.
